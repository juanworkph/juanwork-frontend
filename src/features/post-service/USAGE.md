# Post a Service - Usage Guide

## Quick Start

The Post a Service feature is accessible at:

```
/freelancer/services/post-a-service
```

## Step-by-Step Guide

### Step 1: Basic Details

1. **Enter Project Name**

   - Be descriptive and clear
   - Example: "Build a Modern E-commerce Website"

2. **Write Description**

   - Explain project requirements in detail
   - Include expectations and specific features
   - Character count shown in real-time

3. **Select Project Type**

   - **Fixed Price**: Best for well-defined projects
   - **Hourly Rate**: Best for ongoing work

4. **Set Budget**

   - For Fixed: Enter minimum and maximum budget
   - For Hourly: Enter hourly rate
   - All amounts in USD

5. **Upload Files (Optional)**
   - Click the upload area or drag files
   - Supported formats: PDF, DOC, DOCX, TXT, Images, ZIP
   - Maximum 25MB total
   - Remove files by clicking the X button

### Step 2: Categories & Skills

1. **Choose a Category**

   - Select the most relevant category
   - Options include: Web Development, Mobile, UI/UX, etc.

2. **Add Skills**
   - Start typing to see recommendations
   - Click a recommendation or press Enter to add
   - Add 1-10 skills
   - Remove skills by clicking the X on the badge
   - Manual entry supported for custom skills

**Pro Tip**: Use popular, searchable skills to increase visibility

### Step 3: Choose Upgrades (Optional)

Click on any upgrade card to select/deselect:

1. **NDA ($24.63)** - Freelancers sign non-disclosure agreement
2. **IP AGREEMENT ($24.63)** - Ensures you own all work produced
3. **FEATURED ($11.19)** - Prominent placement in featured section
4. **URGENT ($11.19)** - Shows your project is time-sensitive
5. **PRIVATE ($24.63)** - Hides project from search engines
6. **SEALED ($11.19)** - Hides bids from other freelancers

**Note**: RECRUITER upgrade is currently sold out

The total cost is calculated automatically and shown at the top.

### Step 4: Review & Submit

1. **Review All Details**

   - Basic information
   - Categories and skills
   - Selected upgrades and costs
   - Total budget summary

2. **Submit Service**

   - Click "Submit Service" button
   - Wait for confirmation (loading indicator shown)
   - Success screen appears on completion

3. **After Submission**
   - Service sent for review (24-48 hours)
   - Options to post another or view services

## Navigation

- **Next Button**: Move to next step (validates current step first)
- **Back Button**: Return to previous step (no validation)
- **Step Indicator**: Shows progress (clickable steps in future version)

## Validation & Error Messages

Common errors and solutions:

| Error                                                  | Solution                             |
| ------------------------------------------------------ | ------------------------------------ |
| "Please enter a project name"                          | Project name field is empty          |
| "Please enter a description"                           | Description field is empty           |
| "Please enter valid budget amounts"                    | Budget values must be greater than 0 |
| "Minimum budget cannot be greater than maximum budget" | Swap min/max values                  |
| "Please enter a valid hourly rate"                     | Hourly rate must be greater than 0   |
| "Please select a category"                             | Choose a category from dropdown      |
| "Please add at least one skill"                        | Add at least 1 skill to continue     |
| "You can add up to 10 skills only"                     | Remove a skill before adding more    |
| "Cannot upload X. Total file size exceeds 25MB"        | Remove files to stay under limit     |

## Tips for Success

### Writing Effective Descriptions

- Be specific about requirements
- List deliverables clearly
- Mention timeline expectations
- Include examples if possible

### Choosing Skills

- Use industry-standard terms
- Include primary technologies
- Add specialized skills last
- Avoid redundant skills (e.g., "React" and "ReactJS")

### Budget Guidelines

- Research market rates
- Allow reasonable range for fixed price
- Consider project complexity
- Factor in upgrade costs

### Upgrade Recommendations

| Project Type | Recommended Upgrades |
| ------------ | -------------------- |
| Confidential | NDA + Private        |
| Urgent       | Urgent + Featured    |
| High Budget  | Featured + Sealed    |
| IP Sensitive | IP Agreement + NDA   |

## Keyboard Shortcuts

- **Enter** (in skill input): Add skill
- **Tab**: Navigate between fields
- **Escape** (in dropdowns): Close dropdown

## Mobile Experience

The form is fully responsive:

- Steps collapse into vertical layout
- Touch-friendly buttons and inputs
- Swipe gestures for file removal
- Optimized file picker for mobile

## Troubleshooting

### Files not uploading

- Check file format is supported
- Ensure total size is under 25MB
- Try uploading files individually

### Skills not showing recommendations

- Check spelling
- Try common variations
- Use manual entry if needed

### Form not submitting

- Ensure all required fields are filled
- Check validation messages
- Verify budget values are correct

### Page not loading

- Clear browser cache
- Check internet connection
- Try different browser
